### Featured Projects

**[TeamBoard — Role-Based Project Management Tool](https://teamboard-liart.vercel.app/)**
React, Express, PostgreSQL (Neon)
A Trello/Jira-style tool with per-project role scoping (Admin/Editor/Viewer), enforced through a single backend authorization middleware that re-validates the caller's role on every mutating request. Includes a transactional activity log and fractional positioning for drag-and-drop task reordering, avoiding O(n) rewrites on every move. Optimistic UI updates with automatic rollback on server rejection.
[Live Demo](https://teamboard-liart.vercel.app/) · [GitHub](https://github.com/Syedsafeeruddin/teamboard)

**[Flight Recommendation App](https://flight-booking-app-blush.vercel.app/)**
Next.js, TypeScript, Supabase
A fullstack app integrating a third-party REST API with a custom weighted scoring algorithm (price, duration, stops, rating) to generate recommendations. Server-side authentication and session handling, with a saved-flights feature using optimistic UI updates and automatic rollback on failure.
[Live Demo](https://flight-booking-app-blush.vercel.app/) · [GitHub](https://github.com/Syedsafeeruddin/FlightBookingApp)

**[Live Football Match Dashboard](https://football-dashboard-gilt.vercel.app/)**
React, React Router, REST API
A dashboard consuming a live sports REST API, with client-side polling to keep scores updated in near real time. Uses `React.memo` to reduce unnecessary re-renders as live data updates across the match list.
[Live Demo](https://football-dashboard-gilt.vercel.app/) · [GitHub](https://github.com/Syedsafeeruddin/FootballDashboard)
